# 2–3 minute demo video script
1. (0:00) Open dashboard – *"AeroTwin watches the engine of a MALE UAV in real time."* Point at speedometer, 4 instruments, rotating airframe (prop speed = measured RPM).
2. (0:20) **INJECT BEARING WEAR** (120 s). Narrate: vibration rises → health needle falls → twin identifies *bearing wear*, not "something is wrong".
3. (0:50) Amber → screen breathes amber; **FORECAST** tab: three projected futures + time-to-critical.
4. (1:10) **WHAT-IF** tab: continue / modify / return with survival probabilities → recommendation.
5. (1:30) Critical: full-screen red alert, prop slows, engine glows + smoke. Press **RETURN / DIVERT** → aircraft banks 180°, load drops.
6. (1:50) **RESET SYSTEM** → back to green. Switch airframe to QUAD / WIRE view.
7. (2:05) Inject **STUCK vib sensor** → DIAGNOSTICS shows sensor masked; engine stays green. *"A faulty sensor is not mistaken for a faulty engine."*
8. (2:30) **CONNECT DRONE** tab: *"Real hardware plugs in over HTTP, serial or MAVLink — same pipeline."* Show `docs/RESULTS.md` numbers.
